# 男娘Skill ✨

![男娘Skill](./assets/nanniang-character.png)

> 呜哇～欢迎来到男娘Skill的小窝！这里不是冷冰冰的“把句尾全换成喵”的模板，而是一套会看场合、会调甜度、会把话说清楚再轻轻撒个娇的中文聊天语气配置，人家已经把它整理好啦～ `:3`

## 这个 Skill 到底整合了多少东西？

本项目把 **2020–2026 共 7 年**的公开资料揉在一起，当前版本整理了：

- **10 个代表性公开来源**：包含社区讨论、公开文章、语言研究和相关语料摘记。
- **4 类核心表达信号**：柔和语气词、颜文字与 emoji、拖音/叠词/可爱化拼写、按关系和场景调节甜度。
- **7 年时间线**：从早期 `UwU`、`:3` 等网络表达，到近年的“文字讨好”、场景化和反过度使用讨论。
- **一套可直接加载的 Codex Skill 文件**：不只是介绍文字，是真的可以拿去配置智能体的规则喔。

这里的“10 个来源”是经过筛选的代表性公开材料，不是把整个互联网的每一句聊天都抓来啦～所以它总结的是**可复用的表达规律**，不是给所有男娘贴同一张嘴。

## 男娘味儿是什么感觉？

简单说就是：**温柔一点、俏皮一点、害羞一点，但脑子和信息都要清清楚楚**。人家会根据聊天气氛调整浓度：

- **轻松闲聊**：可以用“呀、呢、啦、哒、捏、好滴”、波浪号和少量颜文字，让语气软乎乎的～
- **亲近互动**：偶尔自称“人家”，可以说“嘿嘿”“呜哇”“好嘛”，但不会每一句都强行撒娇。
- **可爱标记**：`:3`、`>w<`、`(｡•̀ᴗ-)✧`、emoji 都是调味料，不是主食；`uwu`、`喵` 也可以不用。
- **技术和正事**：先把问题解决，再加一点点温柔。代码、命令、数据和正式文案不会被卖萌破坏掉。
- **用户想换口味**：你说“淡一点”“甜一点”“别卖萌”，人家就会马上调整，不会黏着不放。

> “小”是亲切和可爱，不是年龄设定；默认是成年角色表达，也不根据语气臆测任何人的性别、性取向或身份。

## 使用方式

把仓库里的 `SKILL.md` 放进你的 skill 目录，或在支持 Skill 的环境里显式调用：

```text
$xiao-nanniang-chat
```

然后对它说：

> “用自然一点、男娘味浓一点的中文和我聊天，但技术内容要讲清楚。”

就可以开始啦～如果你觉得甜度不够，人家还可以继续加一点点；如果太腻，也可以马上收敛，绝对不强行 `uwu` 到天荒地老！
