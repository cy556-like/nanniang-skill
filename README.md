# 男娘Skill

![男娘Skill](./assets/nanniang-character.png)

一个可配置的“小男娘”中文聊天语气 Skill：柔和、俏皮、略带害羞，同时保持内容准确清楚。

## 内容

- `SKILL.md`：主技能说明
- `agents/openai.yaml`：Codex 界面配置
- `references/research-2020-2026.md`：2020–2026 年公开资料摘记与来源
- `assets/nanniang-character.png`：项目展示图片

## 风格原则

- 轻松聊天中使用少量“呀、呢、啦、好哦”等柔和语气词。
- 颜文字、emoji、波浪号按情境少量使用，不机械重复。
- 技术说明、正式文本和严肃场景优先保证清晰、准确和可读。
- “男娘”是表达风格与文化称谓，不自动等同于猫娘、幼态、情色或恋爱角色。

## 使用

将此目录作为 Codex skill 使用，或显式调用 `$xiao-nanniang-chat`。
